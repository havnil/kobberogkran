# kimkran.no element for element, oversatt til rørlegger

Dato: 13. november 2026. Grunnlag: kimkran.no fanget skjerm for skjerm i 1440×900 og 390×844, og
[den tekniske analysen](2026-11-12-kimkran-analyse.md).

**Mål:** Kobber og Kran skal ha samme oppsett, rekkefølge, rytme og samme type funksjoner som kimkran.no.
Innholdet tilpasses rørlegger.

**Grense:** Vi kopierer ikke deres tekst, bilder, logo eller kode. Vi bygger det samme mønsteret med egen kode,
egne tekster, egne illustrasjoner og Kobber og Kran-merket (farger, logo, Inter/Rubik).

## Det visuelle systemet

| kimkran.no | Hos Kobber og Kran |
| --- | --- |
| Lys, kjølig bakgrunn med hvite paneler og tynne grå rammer. Seksjonene er luftige, med stor avstand | Samme oppbygning med krem bakgrunn, hvite paneler og tynne sandfargede rammer, og samme luft |
| **Display-titler:** svært tunge, kursive og STORE, med siste linje i aksentfarge | Rubik 800, kursiv (skrå), STORE bokstaver, siste linje oransje |
| **Etiketter over titler i monospace** (små, sperret, aksentfarge, «16 TJENESTER») | Samme mønster med systemets monospace, sperret, i mørk oransje |
| Knapper med skrå kant (parallellogram), store bokstaver, sperret | Samme form. Oransje med mørk brun tekst, eller hvit med ramme |
| **Tall i monospace** med enhet i liten tekst (250 tonn, 90 m) | Samme mønster for kr, år, min og km |
| Mørke bånd i full bredde (fotobånd og bunntekst) | Sjokoladebrune bånd |
| **Linje med krok som følger rullingen** langs høyre kant | **Kobberrør langs høyre kant med en kran og en dråpe** som følger rullingen. Dette er firmaets signatur, på samme måte som kroken er det for en kranbil |

## Undersidene

| kimkran.no | Hos Kobber og Kran |
| --- | --- |
| **Tjenesteside:** stor tittel med etikett, faktakort til høyre, brødtekst, ofte stilte spørsmål og skjema nederst | Samme oppbygning for de fem tjenestene. Faktakortet viser våre tre `fakta` |
| **Pris:** pristabell og regneeksempel | Samme, med timepris, servicebil, forbruk, kveld og helg etter avtale, og regneeksempel |
| **Hvilken kran?:** kalkulator og veiledning | Tanksjekken får sin egen plass på siden om varmtvannstank |
| **Kontakt:** «avdelinger» med telefon | Ett kontaktkort for Eirik (telefon, WhatsApp, e-post), og skjema |
| **Stedssider:** `kranbil-<sted>` | Ikke nå. Growth-vurderingen anbefaler høyst én eller to. Områder ligger på én side |
| **Mobil:** «Meny» åpner et panel på hele skjermen. Ringeknappen skjules | Vi beholder «Meny»-panelet, men ringeknappen vises alltid (bunnlinjen) |
